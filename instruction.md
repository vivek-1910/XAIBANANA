Banana Problem –Unit1 Individual Activity (10 Marks)
Problem Title:
Explaining Disease Risk Prediction using Generalized Additive Models (GAM)
Problem Statement:
Design a Python program that loads the disease_risk.csv dataset, trains a Generalized
Additive Model (GAM) to predict disease risk, and explains why the model predicted
“disease” for a selected patient. Visualize the feature-wise contributions influencing
the prediction.
Tasks to be Performed
1. Load and preprocess the disease_risk.csv dataset.
2. Train a GAM model for disease prediction.
3. Select one test instance for which the model predicts “disease.”
4. Explain the prediction using the intrinsic interpretability of the GAM by:
Identifying important contributing features.
Showing whether each feature increases or decreases disease risk.
5. Visualize:
Feature contribution plot for the selected patient.
(Optional) Global shape plots to understand overall feature behavior.
6. Provide a brief interpretation of the explanation in simple language.
Expected Output
1. Trained GAM model
2. Feature contribution visualization for one patient
3. Short written explanation of the prediction
